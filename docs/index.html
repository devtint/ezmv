ezmv moves the files, not the partition: copy, verify, recreate, copy back.

Use

Three commands

  1. Download to your C: drive

    irm https://raw.githubusercontent.com/devtint/ezmv/main/ezmv.ps1 -OutFile "$env:USERPROFILE\ezmv.ps1"

  2. See the plan. Changes nothing.

    powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\ezmv.ps1" -PlanOnly

  3. Run it and follow the prompts

    powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\ezmv.ps1"

Why it is safe

Careful by design

Verified copies

Nothing is deleted until every file is checked. SHA-256 optional.

Survives a power cut

Progress is saved after each step. Run it again to resume.

Asks first

Type YES to start and DELETE before the old drive goes.

Handles BitLocker

Suspends and resumes it. Moves Windows Recovery if needed.

Requirements

Before you start

  • Windows10 or 11
  • DiskGPT, D: right after C:
  • D: driveNTFS, under half full
  • RightsAdministrator
Beta. Back up anything you can't lose, and run with -PlanOnly first.
